# PinShot 0.4.0

本版本加入智能区域截图，并完善贴图标注与隐私处理体验。

## 新功能

- 鼠标移动时自动识别当前应用的 UI 元素，单击即可精确截图。
- 按 `Tab` 在元素与父级区域之间切换；也可随时拖拽进行自由框选。
- 支持多显示器坐标转换和跨屏候选显示。
- 无辅助功能权限或应用不提供元素信息时，自动降级为窗口识别与手动框选。
- 再次按截图快捷键或按 `Esc` 可取消当前截图。

## 体验改进

- 智能候选提示改为中文，并显示当前选区尺寸。
- 完善马赛克、标注渲染、贴图工具栏和敏感内容处理流程。
- 增加智能选区坐标与有效区域的自动检查。

## 验证

- `swift build`
- `swift run PinShot --all-checks`
